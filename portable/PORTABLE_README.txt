MoveMgr Portable

1. Run MoveMgr.exe.
2. Settings and run history are stored in the MoveMgrData folder beside the executable.
3. A new build updates only the executable and preserves MoveMgrData.
4. If the old executable is still open, the new build is written as MoveMgr-<version>.exe in the same folder.
5. Copy both MoveMgr.exe and MoveMgrData when moving the app to another computer.
6. Microsoft Edge WebView2 Runtime is required on Windows 10 and 11.

MoveMgrData contains user-created project settings, file paths, and run history. Review it before sharing a portable folder.
