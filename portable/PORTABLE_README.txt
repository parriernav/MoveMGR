MoveMgr portable

1. MoveMgr.exe를 실행합니다.
2. 설정과 실행 기록은 같은 폴더의 MoveMgrData 폴더에 저장됩니다.
3. 새 버전을 빌드할 때 이 폴더의 실행 파일만 갱신되며 MoveMgrData는 유지됩니다.
   이전 실행 파일이 열려 있으면 같은 폴더에 MoveMgr-버전.exe로 새 파일이 생성됩니다.
4. 다른 PC로 옮길 때 MoveMgr.exe와 MoveMgrData 폴더를 함께 복사하세요.
5. Windows 10/11의 Microsoft Edge WebView2 Runtime이 필요합니다.

MoveMgrData 폴더에는 사용자가 만든 프로젝트 설정과 파일 경로 및 실행 기록이 들어 있으므로 공유할 때 주의하세요.
